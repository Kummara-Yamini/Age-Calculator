# 🎂 Age Calculator

## Description
An interactive Age Calculator built using HTML, CSS, and JavaScript that calculates age in years, months, and days based on the date of birth.

## Purpose
The purpose of this project is to practice JavaScript functions, date handling, conditional statements, and DOM manipulation by creating a useful web application.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Select date of birth
- Calculate age in years, months, and days
- Display the calculated age instantly
- Validate empty date input
- Prevent future dates from being selected as a valid birth date
- Simple and responsive user interface

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Select your date of birth.
5. Click the **Calculate Age** button.
6. View your age in years, months, and days.
